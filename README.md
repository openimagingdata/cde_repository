# Common Data Elements

This repository reflects a periodically updated version of the Common Data Element definitions
as stored and maintained in the ACR/RSNA [RadElement](https://radelement.org) web site.
These definitions formatted as JSON for easy consumption are in the `definitions` directory.

Schemas (as maintained at [the development repo](https://github.com/RSNA/ACR-RSNA-CDEs/)) are
in the `schemas` directory.

Note that currently definitions conform to [version 1.0 of the schema](schema/cde.schema-1.0.json)
(rather than newer [version 1.1 of the schema](schema/cde.schema-1.1.json)).
